# 时煜智能仓储物流管理系统 [简称：时煜智能仓储物流系统] V1.0.0

石家庄时煜源创科技有限公司开发的智能仓储物流管理系统，支持库存同步管理、智能调度、履约发运、售后管理等核心功能。

## 📖 介绍

时煜智能仓储物流管理系统是一款面向现代零售/电商场景的仓储与物流一体化管理平台，通过统一的业务数据中枢，实现仓库作业全流程的可视化与可追溯。系统具备模块化设计，便于企业根据自身发展阶段灵活部署和持续迭代，助力企业完成数字化仓储转型。

主要功能覆盖：采购入库、销售出库、库存盘点与预警、批次与保质期追溯、委外加工管理、仓库空间与货位规划、作业单据流转、报表分析与决策支持等模块。

## ⚙️ 技术架构

后端采用 Spring Cloud 微服务架构；前端采用 Vue 2 + Element UI 技术栈；数据库选用 MySQL，缓存使用 Redis。系统支持多租户隔离，提供标准 RESTful API 及网关安全认证。

### 核心模块

| 模块 | 功能说明 |
|------|----------|
| skyer-order | 仓储作业单管理（入库单、出库单、调拨单、盘点单） |
| skyer-stock | 库存管理与预警（实时库存、批次管理、库存锁定） |
| skyer-goods | 物料/商品主数据管理（规格、条码、包装） |
| skyer-channel | 渠道对接（电商平台、ERP、WMS 集成） |
| skyer-after-sales | 售后与逆向物流（退货入库、换货、报废） |
| skyer-gateway | API 网关（认证、限流、路由分发） |
| skyer-tags | 标签与编码管理（商品标签、库位标签、序列号） |
| front-end | 前端界面（Vue 2 + Element UI） |
